## BRIDGE 3.0 기술이전유형 매핑

기술유형 + 거래유형 조합으로 결정:

1. 기술유형이 저작권(10, '저작권')이면 → **저작권이전**
2. 거래유형이 0/매매/일부양도 → **산업재산권(상표제외)양도**
3. 거래유형이 1/전용실시 → **실시권허여-전용**
4. 거래유형이 2/통상실시/독점적통상실시 → **실시권허여-통상**
5. 거래유형이 3/8/노하우/단위연구노하우 또는 기술유형이 6/노하우 → **노하우이전**
6. 기술자문(거래유형9 또는 기술유형9) → **제외** (BRIDGE 대상 아님)
7. 기타 → 기술유형/거래유형 텍스트 그대로 기재

## 날짜 변환

- `datetime(2025, 5, 27)` → `20250527` (8자리): `d.strftime('%Y%m%d')`
- `datetime(2025, 5, 27)` → `2025.05` (연월): `d.strftime('%Y.%m')`
- 엑셀 셀에 날짜로 표시: datetime 객체 그대로 입력 + `number_format = 'YYYY-MM-DD'`

## 금액 단위 변환

- 원 → 백만원: `value // 1_000_000` (소수점 필요 시 `round(value / 1_000_000, 1)`)
- 원 → 천원: `value // 1_000`
- 천원 → 원: `value * 1_000`
